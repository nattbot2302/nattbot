Ayarlar: GitHub anahtarı
Kuponların repoya kaydedilmesi için bir kez anahtar girmen gerekir. Anahtar sadece bu telefonun tarayıcısında saklanır, sitede yayınlanmaz.
1. Yeni anahtar oluştur sayfasını aç.
2. Token name: kupon, Expiration: 1 yıl.
3. Repository access: Only select repositories → nattbot.
4. Permissions → Repository permissions → Contents: Read and write.
5. Generate token → kopyala → aşağıya yapıştır → Kaydet.
